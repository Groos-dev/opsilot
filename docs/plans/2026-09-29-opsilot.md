## 验证

```bash
npm test          # 幂等键、账本、队列
npm run build     # Next.js 生产构建
```

## 约束

- Pilot / `/api/ops/*` 只读建议，不自动转账  
- 协议三路径对业务开放；运维面 Bearer 令牌  
- 单进程 settle；勿按请求级 serverless 水平扩展热钱包
